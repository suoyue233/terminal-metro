# 地铁 2026 回收员 Demo

## 打开方式

在 Windows 资源管理器中进入本文件夹，双击 **启动Demo.cmd**，即可直接试玩。
需要编辑工程时，双击 **打开编辑器.cmd**；进入编辑器后按 F5 运行。

游戏默认最大化打开，也可以拖动窗口边缘调整大小。按 **F11** 在全屏和最大化窗口之间切换；已打开的旧窗口需重新启动后才有 F11 功能。

两个入口调用你电脑上已有的引擎：

`Z:\soft\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe`

入口不会下载或安装引擎。如果以后移动了引擎，只需用记事本修改两个 cmd 文件中的 `GODOT_EXE` 路径。
`project.godot` 是工程配置文件，不是 Windows 可执行程序；没有关联 Godot 时，直接双击它不会自动运行游戏。

## 车厢版

新游戏从邮电新村的车厢开始。点窗口交易，点柜子整理物品，点床铺休息到第二天并存档。点电脑阅读当天新闻，关闭新闻后选择站点、查看站内外情报，确认扣电前往。

点车门租用防护服、选装备和背包后出站。拾取物品时可以拖进背包，也可以点物品再点目标格。选中或拖拽物品时，滚动鼠标滚轮或按 **R** 旋转。右键或 **Esc** 取消选择。

各站按设施提供不同的货源、收购范围和今日报价。线路图的「站内设施」可查看目的地报价，交易窗口可查附近仍有收购名额的买家。库存和收购额度按站点计算，次日恢复。物品颜色从灰、琥珀、橙到红，分别对应普通、少见、稀有、珍稀。

线路图参考申通地铁 D202501 版中心城区示意图。4 号线环线及 8、10、12、18 号线的中心区站段可前往，每经过一个站段消耗 10 Wh。车厢版存档位于 `saves/cabin_slot.json`，启动时自动读取。

## 横版原型

在 Godot 编辑器打开 `main.tscn`，按 F6 可试玩以下横版原型。

这是根据策划制作的单人 2D 横版可玩原型，包含一座地下站、一张多层地表关卡和一个完整政府回收委托。

- 在车厢住处、回收窗口、充电窗口、维修台、回收管理处和地表检查站之间行走、互动。
- 在多层废墟中移动、跳跃、爬梯，搜集 8 类、15 处物资。背包负重越高，移动越慢。
- 电卡余额与随身电池分别记录；充电同步扣除电卡余额和窗口实际储备。
- 检查区分污染品和管制品：污染过高会被拒收，无证管制品会被没收。
- 两次带货返回后，花 180 Wh 办理特许回收证；持证可进入专项区并为政府回收管制品。
- 将工业控制器交给管理处，领取 210 Wh，完成泵站维修委托，站内泵站随之恢复运行。
- 升级背包、电池，查看每日新闻带来的收购价变化。
- 绕开或驱赶流浪动物；行动失败会失去本趟物资并支付有限接应费用。
- 在住处休息、进入下一天并保存进度。

## 操作

| 按键 | 操作 |
| --- | --- |
| A D / 左右方向键 | 移动 |
| 空格 | 跳跃 |
| W S / 上下方向键 | 在梯子上攀爬 |
| E | 拾取附近物资、使用设施、返回地下 |
| R | 检测附近物资，消耗 2 Wh |
| Tab | 打开或关闭终端与背包 |
| Q | 放下最后一件物资，可以再拾回 |
| F | 驱赶近处动物，有冷却时间 |
| L | 开关手电 |
| M | 静音或开启声音 |
| Esc | 暂停，或关闭当前面板 |
| F11 | 全屏 / 最大化窗口切换 |

面板中的按钮用鼠标点击，也可以使用键盘选择。
地表打开背包时作业倒计时继续；关闭面板后按 Esc 可以暂停。

## 第一轮试玩

1. 在地下站向右行走，充电整备后，到最右侧检查站登记出发。轻装租金 12 Wh。
2. 回收入口附近的铜线，再沿梯子到上层搜集医疗包、手册等物资。
3. 工业控制器属于管制品：前期拿到后直接带回，会在检查时被没收。
4. 返回地表最左侧入口按 E，检查后到回收窗口出售普通物资。
5. 两次带货返回后，在回收管理处花 180 Wh 办证。
6. 持证回收工业控制器，回到管理处交付，完成主要委托。

切割器可在出发时另租，非必需装备。封闭设备箱需要切割器和 18 Wh 随身电量。
地表中段的休整点每趟可使用一次，消耗 20 Wh，补充作业余量并恢复部分体力。

## 验证与工程

已使用本机 Godot 4.7.2，通过 Godot AI MCP 验证：

- 标题按钮和新游戏入口。
- 移动、跳跃、落地、爬梯、上层平台、E 拾取、Q 放下、重复拾取防护、证件门禁。
- 初始 220 Wh 下的完整三趟回收流程：无证没收、出售、二次返回、办证、合法携带、政府交付。
- 住处休息进入下一天，以及单独测试存档的读写恢复。
- 原有 32 项经济、检查、升级和存档检查，另有 1 项检查数量校验，全部通过。

状态测试可以在连接本工程的 Godot AI MCP 中调用 `test_run(suite="game_state")`。
本工程的 `addons/godot_ai` 复制自你本机已有的同版本插件；没有重新下载引擎或插件。
编辑器入口为依赖管理器设置了离线模式，避免自动获取新依赖。

主要源码：

- `scripts/state.gd`：物资、交易、检查、证件、升级、存档。
- `scripts/player.gd`：移动、负重速度、跳跃、梯子。
- `scripts/world.gd`：程序绘制场景、照明、环境动画。
- `scripts/main.gd`：关卡流程、界面、敌人、互动、程序合成声音。
- `tests/test_state.gd`：通过 MCP 执行的状态检查。

## 原型范围

这是一段完成核心回收循环的小 Demo。角色、场景和声音使用程序生成的占位素材；没有使用参考游戏的截图或美术素材。
物资每次出发会重置，便于重复体验和调试。尚未实现多人联机、全上海站点交通、装修、黑市和完整战斗。
